### 📐 LiteCAD
Легковесное 2D CAD-приложение для создания технических чертежей, планов и схем под Windows.
* **Текущая версия:** 0.4.5 Beta

### 🎮 SNW: Live Anyway
Концептуальная хардкорная песочница, построенная на базе философии **Simulation-Native Worlds**.
* **Статус:** Концептуальный дизайн-документ (40+ страниц архитектуры).
* **Фичи:** Мир как живая непрерывная система (вычисляется без наблюдателя), ИИ-модели среды (GameAI), эмерджентная геополитика, перманентная смерть и прокачка реальных навыков человека за монитором.
* **Лицензия:** CC BY-NC-ND 4.0.
---
### 🌐 ASI / GSI — Global Innovation Protocols
Новый архитектурный уровень для обработки идей, семантической оценки и межорганизационного взаимодействия. Протокол для следующего этапа технологической цивилизации.
* **Статус:** Открытый референсный дизайн протокола (Спецификации и Книги в `docs/`).
* **Фичи:** Двухконтурная модель (ASI для идей, GSI для B2B-запросов), семантическое кэширование, сквозная изоляция личности (Identity vs. Reputation) и саморегуляция сети через динамическую слепоту к спамерам.
* **Лицензия:** MIT
* **Репозиторий:** [ASI-GSI-](https://github.com/Siragudin/ASI-GSI-)
---
* ### 🌍 Simulation‑Native Worlds (SNW)
Архитектурная философия и концептуальный фреймворк для создания цифровых реальностей, развивающихся на основе честной материи (Matter), автономных агентов (Agents) и семантических намерений (Intentions) вместо скриптов.
* **Документация:** Авторская трилогия книг (спецификации концепта в `docs/`).
* **Лицензия:** MIT  [https://github.com/Siragudin/SNW]
