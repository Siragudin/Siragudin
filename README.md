## 🛠 Projects

### 📐 LiteCAD (Desktop)
A lightweight, high-performance 2D CAD application for technical drafting, blueprints, and schematic design on Windows.

*   **Status:** `0.4.5 Beta`
*   **Stack:** Windows native (WPF / .NET 10), dual-language engine (RU/EN), precision input matrix, object snapping, semantic vector PDF export
*   **Repo:** [Siragudin/LiteCad](https://github.com/Siragudin/LiteCad)
*   **License:** MIT

### 📐 LiteCAD (Android)
A secure, fast, and fully private mobile 2D CAD editor for on-the-go engineering and precise vector sketching.

*   **Status:** `1.0.0 (RuStore)`, mobile port of the core Windows engine
*   **Stack:** Kotlin, Jetpack Compose, single-activity UDF architecture, 100% offline (zero telemetry, no network permissions), adaptive themes, advanced object snapping, pixel-perfect magnifier, native PDF / DXF (R12) export
*   **Repo:** [Siragudin/LiteCAD-Android](https://github.com/Siragudin/LiteCAD-Android)
*   **License:** MIT

### 🗺️ Geo-Time Capsules
A conceptual architecture and protocol for an interactive, decentralized geo-map of digital time capsules tethered to real-world physical coordinates.

*   **Status:** Conceptual specification / ready for development
*   **Design:** spatial indexing, geofencing, cryptographically enforced long-term unlock timers for deep-time data persistence; React/Vue + MapLibre, FastAPI/Node/Go, PostgreSQL + PostGIS + S3
*   **License:** [CC BY-NC-ND 4.0](https://creativecommons.org)

### 🌐 ASI / GSI — Global Innovation Protocols
A protocol layer for unstructured idea processing, semantic weight evaluation, and frictionless inter-organizational B2B collaboration.

*   **Status:** Open reference design (full specifications and books in `docs/`)
*   **Design:** dual-loop network model (ASI handles proactive creative signals, GSI handles institutional requests), semantic caching to reduce LLM compute overhead, zero-knowledge identity isolation (Identity vs. Reputation), network self-regulation via dynamic peer-to-peer isolation of malicious actors
*   **Repo:** [Siragudin/ASI-GSI-](https://github.com)
*   **License:** MIT

### 🎮 SNW: Live Anyway
A hardcore sandbox concept built directly on the **Simulation-Native Worlds** architectural framework.

*   **Status:** Conceptual design document (`40+ pages` of core architecture)
*   **Design:** infinite hex-cell map with dynamic fractal expansion, four safety rings (Citadel / Suburb / Gray Zone / Wild Territory), permanent character death with medical evacuation insurance, emergent geopolitics and player-driven law, four crafting tiers, macro-logistics with economic blockades
*   **License:** [CC BY-NC-ND 4.0](https://creativecommons.org)

### 🌍 Simulation-Native Worlds (SNW)
An architectural philosophy and development framework for digital realities that evolve through honest physics (Matter), autonomous entities (Agents), and semantic objectives (Intentions) — instead of brittle scripts and hardcoded triggers.

*   **Status:** Book series published (*SNW I — Worlds of Native Simulation*, *SNW II — Material Architecture*, *SNW III — World Architecture*) in `docs/`
*   **Philosophy:** *"Don't play worlds. Live in them."*
*   **Repo:** [Siragudin/SNW](https://github.com)
*   **License:** MIT
